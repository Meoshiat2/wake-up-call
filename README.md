# God First Purpose

A spiritual wake-up call app for people finding themselves, healing, and walking in purpose.

## Features
- Daily uplifting reminders
- Faith-centered mindset prompts
- Recovery and healing language
- Purpose-focused reflections
- Clean, modern single-page experience

## Run locally

```bash
npm install
npm start
```

Then open:

```text
http://localhost:3000
```
